# 保存データの保護とテスト

家計データの保存キーとJSONのバージョンは従来どおりです。ブラウザでの書き込みは `src/storage.ts` の `DataStorage` に集約しています。

## 保存時の扱い

- 起動時にJSONとデータ形を検証します。空文字・不正JSON・未対応バージョン・重複IDなどは初期値で上書きしません。
- 更新版のタブ同士ではWeb Locksで書き込みを直列化し、読み込み時から本体が変わっていた場合は保存を停止します。自動マージは行いません。
- 排他制御が利用できないブラウザでは書き込みを停止します。HTTPSまたはlocalhostと、Web Locks対応のブラウザが必要です。
- 保存前に元データを `yohaku-money-v1:previous` に退避します。退避できない場合も本体を上書きしません。
- 読み込めない本体を利用者がバックアップの読み込み等で明示的に置き換える場合は、元の生データを `yohaku-money-v1:unreadable` に退避します。正常な直前の保存は維持します。
- 同じ内容の保存は何も書きません。連続入力で古い保存要求が遅れて実行されても、最新の入力を巻き戻しません。
- 容量不足や権限エラーでは保存停止を表示します。画面に入力中の内容はJSONに書き出せます。未保存の変更がある状態でページを離れる際は、対応ブラウザで確認を出します。OSによる終了では確認が出ない場合があります。
- 本体が読めないときの書き出しは、初期値ではなく元の生データを出します。有効な直前の退避がある場合は「前回の保存を取り出す」から書き出せます。
- バックアップの読み込み・初期化も保存に成功してから画面へ反映します。確認のキャンセルや不正ファイルでは既存データを変更しません。
- 初期化後も復旧用の記録はブラウザに残ります。完全に削除する場合は、必要なバックアップを確認したうえでサイトのブラウザ保存データを削除します。

競合時はその画面の未保存分をバックアップに書き出してから再読み込みし、新しい記録を確認してください。古い版のタブは同じ排他制御に参加できないので、更新後は既存のタブ・PWAを閉じて開き直してください。

退避は同じブラウザ内の直前1回分で、保存容量も消費します。ブラウザによる保存内容の削除、端末故障、ディスク破損まで防ぐものではありません。端末外へ保管するJSONバックアップの代わりにはなりません。

## テスト

```sh
npm test                  # 計算・検証・保存処理
npm run check             # 上記と両方のビルド・配信ファイル検査
npx playwright install chromium webkit
npm run test:e2e          # ビルド後、ChromiumとWebKitで実ブラウザ検証
```

- `src/storage.test.ts`：破損・読み書き失敗・退避・競合・同時保存・置換・旧形式・バックアップの往復。
- `src/finance.safety.test.ts`：不正データの境界値、操作の非破壊性、独立した台帳モデルと照合する1,500回の編集、繰り返し移行。
- `tests/storage.spec.ts`：実際の画面を通した保存と再読み込み、0円と下書き、バックアップ、初期化、権限・容量の失敗、2タブ同時保存、別オリジンへの移行、オフライン保存、CSP下の動作。

ブラウザテストは4180（LP）と4181（家計簿）で独立したテスト用サーバー・ブラウザコンテキストを作ります。実際に利用しているブラウザや家計データは使いません。CIでは必須チェック `Test and build` の中で両ブラウザを実行します。失敗時は合成データのみを含むレポート・トレースを7日間保存します。

## 大量データの検証

- `src/storage.large.test.ts`：30年分（生活費29,883件・固定費等3,240件）の読み込み・編集・直前退避・再読み込み・別保存先へのバックアップ復元。元の全記録を比較します。
- 10年分の長い日本語メモと、5 MBを超える書き出しファイルの復元を確認します。読み込み上限は16,000,000バイトへ統一しています。UTF-8の日本語と整形用の空白により、書き出しがブラウザ内の保存サイズより大きくなるためです。ファイルサイズと内容形式の検証は維持します。
- 大量データで退避時・本体更新時それぞれの容量不足を再現し、元の本体と復旧用記録、未保存分の書き出しを確認します。
- Chromium・WebKitでも30年分（生活費9,961件）の画面表示・追加・カレンダー・レポート・再読み込み・別コンテキストへの復元を確認します。実際のlocalStorageを合成データで満杯にするケースも実行します。

テストの所要時間は診断情報として記録し、端末差があるため性能の保証値にはしません。メモの長さや他の保存情報により容量に達する時期は変わります。30年間保存できることを保証するテストではありません。自動削除・履歴の切り捨ては行いません。
