# LPの設計

更新：2026-10-21。採用範囲はLPのみ。アプリ本体は今回の変更前の内容を維持する。

**短い紹介と触れるサンプルで、使い始めるイメージが湧くLPにする。**

## 構成

ヒーロー → 操作サンプル → 3つの使い方 → データの保存 → FAQ → 開始ボタン。

「ざっくりつけて、ちゃんと残す。」は維持。紹介は「使った合計を入れるだけ。次の給料日まで、いくら残せそう？」とする。

重複する機能説明や大きな計算表を整理し、数字の意味・0円・固定費との二重計上・バックアップの詳細はFAQへまとめる。FAQでは、現行アプリの「最大」と「このペースで残せるお金」の違いも説明する。

## ズボラな人向けの説明

ヒーローとフッターに入口を設け、短いダイアログで次の3つを示す。

1. 初期設定
2. 思い出した時に使った額を入れる
3. 残せる額を見て使うか決める

初期設定から家計簿へ進める。説明は任意で、閉じるボタン・Escape・背景クリックに対応する。

## 操作サンプル

LP専用の表示を使い、計算には既存の `finance.ts` の関数を利用する。アプリの画面や保存処理には変更を加えない。サンプルの入力はメモリ内だけで扱い、個人の家計データへ保存しない。

サンプルは2026-11-14、10/23〜11/24の期間。手取り250,000円、固定費80,000円、臨時支出10,000円、記録した生活費73,600円、23日分の記録から、見通し54,400円を表示する。今日に1,500円を追加すると52,247円になる。リセットで初期値へ戻る。
